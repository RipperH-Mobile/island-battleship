# ยุทธนาวีเกาะปืน (โฮสต์เอง)

ชุดนี้มี 3 ไฟล์ที่ต้องใช้: `index.html` (เกม), `server.js` (เซิร์ฟเวอร์ห้องออนไลน์ + ส่งไฟล์เกม), `package.json`
ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ต้องมี Node.js 18 ขึ้นไป

## รันในเครื่อง
    node server.js
เปิด http://localhost:3000 (เปลี่ยนพอร์ตด้วย `PORT=8080 node server.js`)
ทดสอบเล่นหลายคนได้โดยเปิดหลายแท็บ

## ขึ้นออนไลน์
ใช้บริการที่รัน Node ได้ เช่น Render, Railway, Fly.io หรือ VPS ของคุณเอง
- Start command: `node server.js` (ไม่ต้องมี build)
- บริการส่วนใหญ่ตั้งตัวแปร `PORT` ให้เอง
- ใช้ HTTPS (บริการข้างต้นให้อัตโนมัติ) เกมจะต่อ `wss://` เอง
- ตรวจว่าทำงาน: เปิด `/health` ต้องได้ `ok`
- ส่งลิงก์เชิญจากหน้าห้องรอได้เลย ลิงก์จะเป็นโดเมนของคุณ

## ตัวเลือก
- `ALLOWED_ORIGINS=https://เกมของคุณ.com` จำกัดให้เฉพาะหน้าเว็บของคุณต่อ WebSocket ได้ (คั่นหลายโดเมนด้วยจุลภาค)

## ข้อจำกัด
- ห้องเก็บในหน่วยความจำของเซิร์ฟเวอร์ ถ้ารีสตาร์ตเซิร์ฟเวอร์ ห้องที่เล่นอยู่จะหาย ให้รันเพียง 1 instance
- ห้องละไม่เกิน 8 การเชื่อมต่อ ข้อความไม่เกิน 8 KB
- ใครรู้รหัสห้องก็เข้าได้ และผังเรือผ่านห้องเดียวกัน เหมาะกับเล่นกับเพื่อน ไม่เหมาะกับแข่งจริงจัง
- เจ้าของห้องเป็นคนคุมเกม ถ้าเจ้าของหลุด สามารถเปิดหน้าเดิมแล้วกด "กลับเข้าเกม" เพื่อเล่นต่อได้
